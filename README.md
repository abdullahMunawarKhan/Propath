# ProPath - Career Guidance Web App 🎓✨

ProPath is a career exploration and AI-powered guidance platform built with React and Supabase.

## 🚀 Features

- ✅ Student login & signup
- ✅ Domain-based quiz with result evaluation
- ✅ Dynamic roadmaps and competitive exam guides
- ✅ AI chatbot integration (Chatbase)
- ✅ Password reset & update flow
- ✅ Career Explorer with flipping cards and categories

## 🔧 Tech Stack

- React + Tailwind CSS
- Supabase (Auth & Database)
- Cohere API (Chatbot)
- GitHub (Version Control)

## 📦 Setup & Run

```bash
npm install
npm run dev
